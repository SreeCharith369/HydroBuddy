# Messages

HydroBuddy message text lives in `data/messages.json` for future runtime use.

This document keeps the editorial direction visible while the project is still early: messages should be short, friendly, and calm.

Milestone 1.2 also adds event, theme, and animation metadata foundations. Message text remains separate from those concerns so future UI components can ask for words without knowing about storage, animation flow, or state transitions.
